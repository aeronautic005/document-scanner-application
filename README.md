# Document Scanner

A modern, mobile-optimized productivity application for capturing, organizing, and managing scanned documents.

## Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Design System**: Mobile-first productivity layout with clean slate & indigo theme

## Features & Navigation (Foundational UI)
- **Mobile Navigation Bar**: Fixed bottom bar with ergonomic touch targets for:
  - **Dashboard**: Quick action triggers, scan statistics, and recent activity overview.
  - **History**: Searchable list of past scanned documents, tags, filters, and document preview cards.
  - **Settings**: App preferences, default scan resolution, cloud sync, and storage usage metrics.
- **Responsive Architecture**: Optimized for mobile viewports with centered shell container for larger screens.

## Project Setup

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
